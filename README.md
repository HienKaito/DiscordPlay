# Anime TCG Discord Bot

Bot thu thập nhân vật anime dạng Trading Card Game cho Discord.

## Tính năng

- 🎴 **Auto Spawn**: Tự động spawn nhân vật mỗi 5 phút
- ❤️ **Claim**: React để thu thập nhân vật
- 📚 **Collection**: Xem bộ sưu tập của bạn
- 🔍 **Search**: Tìm kiếm nhân vật

## Cài đặt

```bash
npm install
```

## Cấu hình

1. Copy `.env.example` thành `.env`
2. Điền Discord Bot Token

```bash
cp .env.example .env
```

## Chạy bot

```bash
npm start
```

## Commands

| Lệnh | Mô tả |
|------|-------|
| `/setchannel` | Set channel spawn (Admin) |
| `/collection` | Xem bộ sưu tập |
| `/search <tên>` | Tìm nhân vật |
